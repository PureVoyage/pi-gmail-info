pi gmail 隐私权政策

生效及更新日期：2026 年 10 月 19 日

pi gmail 是应用所有者用于管理本人 Gmail 账号的个人工具，使用开源 Pi Gmail 扩展运行于所有者授权的设备。本政策说明该个人集成和本说明网站的数据处理方式。

1. 访问哪些数据

在获得 Google 授权后，工具按用户请求访问邮件的发件人、收件人、主题、时间、正文、标签、状态和附件名称等信息。执行发送或回复时，还会处理用户提供的收件地址和邮件内容。

工具使用 gmail.modify 和 gmail.send 权限完成读取、搜索、发送及邮件状态管理，并在授权设备保存 OAuth 客户端凭据和访问令牌。本说明网站不接收或保存这些邮箱凭据。

2. 数据用途

邮件数据用于完成所有者提出的搜索、阅读、内容整理、起草、发送、回复和邮箱管理任务。发送、回复及修改邮箱状态需要插件的交互确认。

本工具不设置邮件数据买卖、广告投放或商业用户画像功能。

3. AI 模型服务商与第三方处理

通过 Pi 处理邮件时，进入对话的邮件内容可能随提示词和上下文发送给用户选择的 AI 模型服务商，以生成回答或执行所请求的任务。邮件数据并非始终只在本机处理。

模型服务商、转发服务、数据保留期限及使用规则取决于用户的 Pi 配置和所选服务商政策。本工具不提供模型服务，也不能代替这些服务商作出不记录、不保留或不训练的承诺。使用前，所有者应确认所选服务适合处理其邮件数据。

Google API 数据的使用与向其他应用的传输应遵循 Google API 服务用户数据政策及其中的有限使用要求。

4. 存储与保留

  • OAuth 客户端凭据和令牌保存在授权设备的受限目录中，文件只允许设备所有者访问。
  • 进入 Pi 对话的邮件和模型回答可能随对话历史保存在设备上，其保留和备份方式取决于本机 Pi、客户端及用户配置。
  • 模型服务商已经接收的数据依其适用政策和用户设置处理；本说明网站不托管邮箱或对话历史。

5. 撤销授权与删除

所有者可以在 Google 账号的第三方连接管理中撤销本应用访问权限，也可以通过插件的退出命令删除本机令牌。

本机 OAuth 客户端凭据、Pi 对话历史及备份需要由所有者另行管理和删除。撤销 Google 授权不会自动删除已经保存的邮件内容或模型服务商已经处理的数据；后者应按对应服务商的设置及隐私政策处理。

6. 网站访问

本网站仅提供应用介绍和本政策，没有登录、邮件上传、广告或第三方分析脚本。静态托管平台可能按其隐私政策记录常规访问日志。若使用 GitHub Pages 托管，适用 GitHub 隐私声明。

7. 联系方式与政策变更

本应用仅供所有者个人使用，支持联系方式以 Google 授权页面显示的支持邮箱为准。

如数据处理方式发生变化，本页会相应更新并修改顶部日期。本应用与 Google 没有隶属关系。
